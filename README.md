# gms-cesfam

## Comandos útiles

```bash
pip install -r requirements.txt
```
El comando sirve para instalar las librerías desde el archivo requirements.txt (pd: ejecutar con el entorno virtual activado y estar dentro de la carpeta de backend)
```bash
pip freeze > requirements.txt
```
cada vez que instales una librería nueva en el backend se usa este comando para actualizar el alrchivo requirements.txt para quedar al dia con las versiones

```bash
git branch
```
para ver las ramas (la rama con el simbolo * muestra en la rama en la que te encuentras)

```bash
git switch <nombre_de_la_rama>
```
para cambiar de rama
